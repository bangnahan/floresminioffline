# Pekanbaru Mini Offline Charity Run For Flores 2026 (#RunForFlores)
Landing Page resmi event 5K Fun Run diselenggarakan oleh **Yakesma Riau (Yayasan Kesejahteraan Madani)**.

## 📁 Struktur Berkas
- `index.html`: Landing page modern (Tailwind CSS, Lucide Icons, Vanilla JS interaktif)
- `images/`: Berkas aset foto resmi:
  - `poster-hero.jpg`: Poster utama kampanye
  - `medali-5km.png`: Medali import 5KM finisher
  - `jersey-singlet.jpg`: Jersey model singlet
  - `jersey-pendek-depan.png` & `jersey-pendek-belakang.png`: Jersey model lengan pendek
  - `jersey-panjang.jpg`: Jersey model lengan panjang

## 🚀 Cara Menjalankan
Cukup buka berkas `index.html` langsung di browser favorit Anda (Google Chrome, Safari, Edge), atau jalankan local server jika diperlukan:
```bash
# Opsi 1: Menggunakan Python simple HTTP server
python3 -m http.server 3000

# Opsi 2: Menggunakan npx serve
npx serve .
```
Akses di browser: `http://localhost:3000`
